# ⏱ 스마트 화면보호기 지연기 (Smart Screensaver Extender)

윈도우 작업 환경에서 마우스 강제 조작 없이, **사용자 유휴 시간을 감지하여 원하는 주기와 횟수만큼만 화면보호기 작동을 안전하게 연장**하는 초경량 트레이 상주형 포터블 유틸리티입니다.

---

## 🌟 핵심 특징

1. **무간섭(Zero-Interference) 절전 제어**
   - 마우스 커서를 흔들거나 가상 키를 난사하지 않고, Windows 공식 커널 API(`SetThreadExecutionState`)를 통해 절전 타이머만 초기화합니다.
   - 마우스 클릭 빗나감이나 커서 튐 등의 업무 방해가 전혀 없습니다.

2. **제로 부하(0.00% CPU) 스마트 지연 스케줄러**
   - 윈도우 OS가 내부적으로 기록하는 타임스탬프(`GetLastInputInfo`)를 활용합니다.
   - 무식한 1초 단위 폴링 대신, **다음 신호 발생 예정 시점까지 동적으로 타이머를 잠재우는 적응형(Adaptive) 스케줄링**을 적용하여 CPU/배터리 부하가 사실상 0입니다.

3. **자동 화면보호기 시간 감지 & 예상 잠금 시간 산출**
   - Windows 시스템의 현재 화면보호기 대기시간($T_{\text{screensaver}}$)을 자동으로 읽어옵니다.
   - 사용자가 설정한 주기($I$)와 횟수($N$)에 따라 **"최종 몇 분 뒤에 화면보호기가 켜지는지"**를 실시간으로 자동 계산하여 보여줍니다:
     $$\text{최종 예상 잠금 시간} = (N \times I) + T_{\text{screensaver}}$$

4. **실수 방지 안전 가드 (Safety Guards)**
   - **주기 상한선**: `화면보호기 설정 시간 - 1분` (예: 5분 설정 시 최대 4분). 화면보호기보다 긴 주기를 설정해 중간에 화면이 꺼지는 실수를 원천 방지합니다.
   - **주기 하한선**: 최소 1분
   - **횟수 범위**: 1회 ~ 최대 100회 (오버플로우 방지)
   - 경계값 도달 시 UI 및 트레이 메뉴의 증가/감소 화살표가 자동으로 비활성화(`Disabled`)됩니다.

5. **완전 독립형 포터블 (No Installation)**
   - 별도 인스톨러 없이 단일 `.exe` 실행 파일로 동작합니다.
   - 동적 아이콘 생성 기술을 적용하여 외부 `.ico` 파일 없이 단독 실행 가능합니다.

## 🖥 사용 방법 및 UI

### 1. 트레이 아이콘 우클릭 (Quick Context Menu)
- **최상단**: `[예상 잠금: 약 13분 후] (기본 5분 + 연장 8분)` 실시간 표시
- **주기 조절**: `▲ 주기 1분 증가` / `[ 주기 : 3분 ]` / `▼ 주기 1분 감소` (가드 적용)
- **횟수 조절**: `▲ 횟수 1회 증가` / `[ 횟수 : 2회 ]` / `▼ 횟수 1회 감소` (가드 적용)
- **활성화 토글**: `✔ 활성화` (즉시 기능 ON/OFF)
- **About**: 마우스 호버 시 우측으로 서브메뉴가 열리며 개발자 ID(`slalglel`) 표시
- **프로그램 종료**: 트레이에서 완전히 종료

### 2. 트레이 아이콘 더블클릭 (세부 설정 창)
- 화면 중앙에 직관적인 미니 윈도우가 표시됩니다.
- 좌우 화살표(`[ ◀ ]`, `[ ▶ ]`)로 주기와 횟수를 조절할 수 있습니다.
- 현재 사용자의 유휴 상태 및 남은 연장 횟수를 실시간으로 모니터링할 수 있습니다.
- 창을 닫아도 트레이로 안전하게 최소화 상주합니다.

### 3. 부팅 시 자동 시작 등록 방법
1. `Win + R` 키를 누른 뒤 `shell:startup` 입력 후 엔터
2. 열린 '시작프로그램' 폴더에 `ScreensaverExtender.exe`의 **바로가기**를 생성하여 붙여넣기

## 📥 다운로드 안내 (사내망 / Releases 탭 차단 환경)

Releases 탭이나 개별 `.exe` 다운로드가 사내 보안망에 의해 차단된 경우:
1. GitHub 저장소 메인 화면 상단의 초록색 **`<> Code`** 버튼 클릭
2. **`Download ZIP`** 선택하여 전체 소스코드 ZIP 다운로드
3. 압축 해제 후 **`dist/`** 폴더 내의 실행 파일 사용:
   - **`dist/ScreensaverExtender.exe`** : 무설치 즉시 실행 파일 (24 KB)
   - **`dist/ScreensaverExtender_net48.zip`** : 압축 패키지 버전 (11 KB)

## 🛠 빌드 및 개발 환경

- **타겟 프레임워크**:
  - `net48` (.NET Framework 4.8) : Windows 10/11 모든 PC에 기본 내장되어 있어 추가 설치 없이 즉시 실행 (< 1MB)
  - `net8.0-windows` : 최신 .NET 8 런타임 호환

### CLI 빌드
```bash
# .NET Framework 4.8 빌드
dotnet build -c Release -f net48

# .NET 8 단일 파일 발행
dotnet publish -c Release -f net8.0-windows -r win-x64 --self-contained false -p:PublishSingleFile=true
```
